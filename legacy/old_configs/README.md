# Config
The file `config.yaml` contains the configurable options used in the training pipeline.
## Options
- `loss_type`: the loss function used. E.g. `cross_entropy`, `vgg19`.
- `shade_format`: number of digits in the tone section used. `X` for X.X, `XX` for X.XX, `XXX` for X.XXX.
- `color_space`: the colour space used in training. E.g. `RGB`, `LAB`.
